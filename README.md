# Credit Scoring Strategy — Система оценки кредитного потенциала

**Python-приложение для расчёта кредитного потенциала заёмщика на основе двух стратегий: дохода и кредитной истории. В составе — прототип десктопного GUI-банк-клиента с авторизацией, переводами и управлением профилем.**

Проект демонстрирует применение паттерна **Strategy** для изолированной логики кредитного скоринга и базовую модель банковской предметной области (пользователь, счёт). Реализован на чистом Python — без внешних зависимостей (только стандартная библиотека, включая `tkinter` для GUI).

## 🚀 Ключевой функционал

### Credit Scoring Engine (`src/credit_scoring/`)

| Стратегия | Входные данные | Критерии оценки | Результат |
|---|---|---|---|
| **По доходу** | Ежемесячный доход + желаемая сумма кредита | доход ≥ 60k и сумма ≤ 50k → Высокий; доход ≥ 40k и сумма ≤ 30k → Средний; иначе → Низкий | Категория потенциала |
| **По кредитной истории** | Кредитный рейтинг (FPS-шкала) | ≥ 700 → Высокий; 600–699 → Средний; < 600 → Низкий | Категория потенциала |

- **CreditCalculator** — контекстный класс, переключающий стратегию в runtime.
- **CLI** — консольный ввод с интерактивным выбором стратегии.

### Bank Client GUI (`src/bank_app/`)

- **Авторизация** по логину/паролю (in-memory).
- **Дашборд** — приветствие + отображение баланса.
- **Переводы** между пользователями (с валидацией: достаточность средств, самоперевод).
- **Пополнение счёта** (с валидацией ввода).
- **Редактирование профиля** — смена имени, фамилии, пароля; live-обновление приветствия.
- **Демо-режим** — данные хранятся в памяти, БД не требуется.

### Схема паттерна Strategy (Scoring Engine)

```
CreditCalculator (Context)
 └── strategy: BaseStrategy
      └── calculate(user_data) → "Высокий" | "Средний" | "Низкий"

BaseStrategy (Interface)
 ├── IncomeAndLoanBasedStrategy    # доход + сумма
 └── CreditHistoryBasedStrategy    # кредитный рейтинг
```

## 💻 Локальное развертывание

### 1. Клонирование

```bash
git clone https://github.com/<user>/credit-scoring-strategy.git
cd credit-scoring-strategy
```

### 2. Виртуальное окружение (опционально)

```bash
python3 -m venv .venv
source .venv/bin/activate          # Linux / macOS
# или .venv\Scripts\activate       # Windows
```

### 3. Зависимости

```bash
pip install -r requirements.txt
# → ничего не установится, всё уже есть в stdlib
```

### 4. Запуск

**Credit Scoring (CLI):**
```bash
python -m src.credit_scoring.main
```

**Bank App (GUI):**
```bash
python -m src.bank_app.main
```

> **Важно:** Команды выполняются из корня проекта (`credit-scoring-strategy/`).  
> Для GUI требуется дисплей (не работает в «головном» сервере без X11/VcXsrv).

### 5. Переменные окружения

```bash
cp .env.example .env
# Пока не используются — задел на будущее
```

## 🔌 Сценарии использования

### Credit Scoring (консоль)

| Шаг | Действие | Пример ввода |

| 1 | Выбор стратегии | `1` — по доходу / `2` — по кредитной истории |
