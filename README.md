# Credit Scoring Strategy — Система оценки кредитного потенциала

Python-приложение для расчёта кредитного потенциала заёмщика на основе двух стратегий: дохода и кредитной истории. В составе — прототип десктопного GUI-банк-клиента с авторизацией, переводами и управлением профилем. Проект демонстрирует применение паттерна **Strategy** для изолированной логики кредитного скоринга.

---

## 🛠 Технологический стек

При проектировании архитектуры приложения упор делался на модульность и простоту.

*   **Язык разработки:** Python 3.10+
*   **Архитектурные паттерны:** Strategy, OOP (наследование, полиморфизм)
*   **GUI:** Tkinter
*   **Инструменты тестирования:** PyTest (планируется)

> Зависимостей нет — только `stdlib`. `requirements.txt` оставлен как точка расширения.

---

## 🚀 Ключевой функционал

*   **Credit Scoring Engine:** Две стратегии оценки — по доходу (ежемесячный доход + желаемая сумма) и по кредитной истории (FPS-шкала)
*   **CreditCalculator:** Контекстный класс, переключающий стратегию в runtime
*   **CLI:** Консольный ввод с интерактивным выбором стратегии
*   **Bank Client GUI:** Авторизация по логину/паролю, дашборд с балансом, переводы между пользователями, пополнение счёта, редактирование профиля

## 📁 Архитектура и структура проекта

В проекте используется классическая OOP-архитектура с паттерном Strategy. Это обеспечивает независимость алгоритмов скоринга от клиентского кода.

```text
credit-scoring-strategy/
├── .gitignore                     # Исключения: .venv, __pycache__, .idea
├── .env.example                   # Шаблон переменных окружения
├── README.md                      # Текущая документация
├── requirements.txt               # Зависимости (пока пусто)
├── src/
│   ├── __init__.py
│   ├── credit_scoring/            # Модуль кредитного скоринга
│   │   ├── __init__.py
│   │   ├── calculator.py          # CreditCalculator (контекст)
│   │   ├── strategies.py          # BaseStrategy + реализации
│   │   └── main.py                # CLI-точка входа
│   └── bank_app/                  # Модуль банковского GUI
│       ├── __init__.py
│       ├── models.py              # User, BankAccount, Profile
│       ├── gui.py                 # BankAppGUI (tkinter)
│       └── main.py                # GUI-точка входа
└── docs/
    └── КП_бИСТ235_Рогачев.docx    # Курсовая работа
```

### Схема паттерна Strategy

```
CreditCalculator (Context)
 └── strategy: BaseStrategy
      └── calculate(user_data) → "Высокий" | "Средний" | "Низкий"

BaseStrategy (Interface)
 ├── IncomeAndLoanBasedStrategy    # доход + сумма
 └── CreditHistoryBasedStrategy    # кредитный рейтинг
```

## 💻 Локальное развертывание

Для запуска проекта в изолированном окружении вам понадобятся **Python 3.10+** и Git.

### 1. Клонирование репозитория

```bash
git clone https://github.com/<ваш-username>/credit-scoring-strategy.git
cd credit-scoring-strategy
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корневой директории проекта по образцу `.env.example` (пока не используются — задел на будущее).

### 3. Запуск

**Credit Scoring (CLI):**
```bash
python -m src.credit_scoring.main
```

**Bank App (GUI):**
```bash
python -m src.bank_app.main
```

> Для GUI требуется дисплей (не работает в «головном» сервере без X11/VcXsrv).

## 🔌 Сценарии использования

### Credit Scoring (консоль)

| Шаг | Действие | Пример ввода |
|---|---|---|
| 1 | Выбор стратегии | `1` — по доходу / `2` — по кредитной истории |
